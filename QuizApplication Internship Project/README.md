# Quiz Application

## Description
This is a Quiz Application developed using Core Java, JDBC, and MySQL.

## Features
- User Registration and Login
- Quiz based on Category and Difficulty Level
- Score calculation
- Result storage

## Technologies Used
- Java
- JDBC
- MySQL

## How to Run
1. Create a new Java project in Eclipse
2. Copy the src folder into the project
3. Add MySQL Connector JAR
4. Create database and tables
5. Run the main class
